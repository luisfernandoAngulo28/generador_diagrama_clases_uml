# Tareas para el Examen Final — Grupo 43

Las cuatro tareas que el docente pidió en la clase del 2do Parcial como parte
del examen final:

1. [Código de Ética del Ingeniero de Software (ACM/IEEE-CS)](01_codigo_de_etica.md):
   los 8 principios y cómo los aplicamos en el proyecto.
2. [Terminología de la ingeniería de software según la IEEE](02_glosario_ieee.md):
   IEEE 610.12 / ISO/IEC/IEEE 24765, con cada término ejemplificado en el
   proyecto.
3. [Pasado, presente y futuro del software, y la Crisis del Software](03_pasado_presente_futuro_crisis.md):
   incluye nuestra respuesta a «¿hemos superado la crisis?».
4. [Comparación de 8 ciclos de vida / estrategias](04_comparacion_ciclos_de_vida.md):
   enfoque, ventajas, desventajas y cuándo usar cada una, con un cuadro
   comparativo.

Son borradores para revisar entre los dos antes de entregarlos. Las definiciones
están parafraseadas; las fuentes están al final de cada archivo.
